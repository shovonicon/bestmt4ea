## How to use this

1. Gone and redirected URLs need no work. Re-submit the sitemap and let Google recrawl.
2. Live posts that meet the rules: ask Google to recrawl them in the order of the first table (Search Console, URL Inspection, Request indexing, about 10 a day), and keep linking to them internally.
3. Live posts with listed issues: rewrite them (`npm run rewrite-queue` consumes `src/data/seo-priority.json`).
4. Decide each missing path: redirect to an equivalent page, or 410.
