TradingView CSV Export Guide

A practical checklist for exporting chart data to CSV, what each method captures, and how to check the file before you use it. Version 1.0 · Free to use, print and share with credit to bestmt4ea.com

1. Start with what your account can do

Free TradingView accounts can copy the values shown on the screen. A full historical export depends on the plan you hold, so check your own account before you build a workflow around any one option. This guide does not assume a plan, and it does not promise a complete file.

3. Method A: copy the Data Window

1
Open the chart and set the symbol, exchange and timeframe. Write them in your notes.
2
Scroll left until the history you need is loaded. The chart only holds bars that are loaded.
3
Hover over each bar to read the Data Window, or copy the values for the range you need.
4
Paste into a spreadsheet with a header row: time, open, high, low, close, volume.
5
Save as CSV and record the first and last timestamp beside the file.

4. Method B: chart-data export

If your plan includes a chart-data export, use it for longer ranges. Read the current option on your own screen, not an old screenshot. Then confirm three things: the file covers the range you asked for, the column order and time format are as expected, and the first and last ten rows match the chart.

5. Method C: indicator values with Pine Script

A Pine Script indicator can calculate any value for each bar and plot it. The Data Window then shows that value beside the price, so it can be copied with the candles. Test the script on a few bars where you already know the answer before you build a dataset from it. The official Pine Script documentation is the reference for functions and plotting.

6. Method D: broker or public feed

Your broker's MetaTrader terminal can export history for a symbol, and that history matches the prices your EA sees. Public feeds can suit research, but check the licence and usage terms before you download or redistribute the data. Pick one source for a project and keep it, because mixing sources creates differences that are hard to trace.

The five checks before you calculate anything
☐ Count. Compare the row count with the bars expected for the period and timeframe.
☐ Order. Timestamps rise from the top row to the bottom row.
☐ Prices. High is never below open or close; low is never above them.
☐ Time zone. Note whether timestamps are local or exchange time.
☐ Sample. Match three bars in the file against the chart, all six values each.

7. What a candle export cannot tell you

A candle export records one summary per bar. It does not show the order of prices inside the bar, so it cannot show which level was reached first. It also usually shows traded prices, not the bid and ask you pay, so spread is missing. Add a spread assumption to any test, and treat a candle-based result as a rough guide until it is tested on data that includes spread and fills.

8. Keep a repeatable record

Name each file with symbol, timeframe, source, date range and export date, for example XAUUSD_M15_source_2025-01-01_to_2025-12-31_exported-2026-10-22.csv. Keep the raw export unchanged and make cleaning or calculations in a copy. Record the method and the plan that produced the file, because features change.

9. Before you rely on any result

An exported file shows history, not the future. Use it to form a hypothesis, then test on data you did not use to build the rule, and on a demo account before any live capital. Trading carries a real risk of loss. Past results do not guarantee future performance, and this guide does not promise any outcome.
