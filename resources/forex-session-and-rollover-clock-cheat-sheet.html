3. Weekly traps

  • Monday open: weekend gaps; let the first hour settle before trusting signals.
  • Friday New York afternoon: liquidity leaves early; many EAs should have a Friday rule — check yours exists.
  • Month-end and holidays: bank holidays in London or New York quietly halve the market; your calendar, not your EA, usually knows first.
  • Daylight-saving changeover weeks (March/April, October/November): server offsets shift; EA session inputs written in server time survive, ones written from memory do not.
The clock rule: every time-based setting in every EA you run should be written in broker server time, on this sheet, verified against the Market Watch clock today — not remembered from when you set it up.
