MQL4/MQL5 Compile Error Fix Guide

A compile error is MetaEditor telling you the code cannot become a runnable program yet. The error list looks hostile, but almost every failed install traces back to the same small set of causes. Fix errors from the top of the list down — the first error is usually the real one, and the rest are its echoes.

How to read the error list

  • Double-click the first error: MetaEditor jumps to the exact line.
  • Fix one error, recompile, and read the new list. Never fix five lines blind.
  • Warnings are not errors: a file with warnings still produces a working .ex4/.ex5.

The errors you will actually meet

ErrorWhat it meansFix
'X' - undeclared identifierA variable or function name is used before it exists, or is misspelled.Check spelling and capitalisation; declare the variable above its first use; confirm any #include file is present.
undeclared identifier 'OrderSend' (MQL5)MQL4 trading code compiled as MQL5.Use the MQL5 trade classes (CTrade) or compile the file in MT4. The languages are cousins, not twins.
'(' - unexpected token / unbalanced bracesA missing ) or } earlier in the file.Use MetaEditor's brace matching: click a brace and find its partner. The reported line is often below the real gap.
cannot open file '...mqh'An included library file is missing.Place the .mqh in MQL4/Include (or MQL5/Include), keeping the vendor's folder structure.
wrong parameters countA function is called with too many or too few arguments.Compare the call with the function definition; vendor updates often change the argument list.
array out of rangeCode reads an index the array does not have (runtime, appears in the log).Check indicator buffer warm-up: wait for enough bars (Bars > 100) before testing the EA live.
'string' - type mismatchA value is used as the wrong type.Convert explicitly (IntegerToString, StringToDouble) instead of letting the compiler guess.
file compiled for a different platformAn .ex4 opened in MT5 or an .ex5 in MT4.No fix exists: get the build made for your platform from the vendor.

When the file compiles but the EA still fails

  • Experts log shows "cannot load library" — the .dll is missing or DLL imports are disabled.
  • "Invalid stops" — your stop distance is below the broker's minimum; raise the buffer, not the lot size.
  • "Off quotes" / requotes (MT4) — the price moved during the request; widen the allowed slippage/deviation in the EA inputs.
  • "Trade is disabled" — the symbol is view-only on this account, or the market is closed.
Honesty rule: never edit a purchased EA's risk code (lot sizing, martingale steps, stop logic) to silence an error. If the vendor's file does not compile as delivered, that is the vendor's bug — send them the first error line and the build number.
