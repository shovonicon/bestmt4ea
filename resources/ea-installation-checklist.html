MT4/MT5 Expert Advisor Installation & Activation Checklist

Most 'my EA does not work' reports are installation problems, not strategy problems: the file is in the wrong folder, AutoTrading is off, or the broker's symbol suffix was never matched. Work through this checklist in order and tick each box before you judge any robot.

1. Before you install

  • Download the EA file (.ex4 for MT4, .ex5 for MT5) and any .set preset files from the original source only. Scan the file before use.
  • Confirm the file matches your platform: an .ex4 will not run on MT5 and an .ex5 will not run on MT4.
  • Check the licence terms: how many accounts, which account numbers, and whether a demo account is allowed for testing.
  • Write down your maximum demo-test loss (money or %) before the EA places its first trade.

2. Put the file in the right place

  • In the terminal: File → Open Data Folder.
  • MT4: copy the .ex4 into MQL4/Experts. MT5: copy the .ex5 into MQL5/Experts.
  • Indicators go in MQL4/Indicators (or MQL5/Indicators) — an indicator in the Experts folder will never attach.
  • Libraries (.dll) go in MQL4/Libraries only if the vendor instructs it; leave "Allow DLL imports" off otherwise.
  • Right-click Navigator → Experts and choose Refresh, or restart the terminal.

3. Terminal settings that silently block EAs

  • Tools → Options → Expert Advisors: enable "Allow algorithmic trading" (MT5) / "Allow automated trading" (MT4).
  • The AutoTrading / Algo Trading button in the toolbar must be green.
  • On the chart: the smiley / hat icon next to the EA name must not show a cross. A crossed icon means trading is disabled for that chart.
  • Check the Experts and Journal tabs for the exact error line before changing any setting — the log names the real cause.

4. Attach and configure

  • Open the exact symbol and timeframe the vendor specifies. Match broker suffixes (EURUSD vs EURUSD.m) — most "no trades" cases are a suffix mismatch.
  • Drag the EA onto the chart, load the vendor's .set file if one is provided, and change only the lot/risk inputs on the first run.
  • Confirm your account type is allowed (some EAs misbehave on cent or swap-free accounts) and that hedging vs netting mode matches (MT5).
  • Leave the EA running for a full session. An EA that trades twice a week cannot be judged in an afternoon.
Stop rule: if the Experts log shows errors you cannot identify, stop. Do not raise the lot size, do not switch to a live account, and do not disable your broker's protections to "make it trade". An EA you cannot explain is an EA you cannot risk-manage.
