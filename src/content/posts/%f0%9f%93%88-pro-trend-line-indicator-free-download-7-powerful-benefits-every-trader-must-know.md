## 📥 How to Install Pro Trend Line Indicator (Step-by-Step)

### 🔹 For MetaTrader 4 / 5

1.  Download the indicator file (.ex4 or .ex5).
2.  Open MT4/MT5 → File → Open Data Folder.
3.  Go to MQL4/MQL5 → Indicators.
4.  Paste the file.
5.  Restart platform.
6.  Drag indicator onto chart.
