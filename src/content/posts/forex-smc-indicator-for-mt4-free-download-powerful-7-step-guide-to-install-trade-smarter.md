## Why Does a Free SMC Indicator Often Fail on the First Try?

Most failed installs have a short list of causes. The file is in the wrong folder. The terminal blocks automated trading. The broker's symbol name has a suffix that does not match the one the vendor used. The file type does not match your platform. The indicator needs a setting you have not turned on.

The checklist starts from one plain observation: most "my EA does not work" reports are installation problems, not strategy problems. That matters for SMC indicators too. When a chart looks empty, the cause is usually something you can check in five minutes, not a flaw in Smart Money Concepts itself.

Free files add extra uncertainty. A paid product usually comes with a support page, a version history and a seller you can contact. A free file from an unknown source may come with none of these. You may not know who wrote it, what it changes on your system, or whether it was edited after it was shared. You need a method, not luck.

That is why this guide treats installation as a process with checks at each stage. Check the file. Check the folder. Check the terminal. Check the chart. Check the results on demo. Skipping one stage is how beginners end up blaming the indicator for a problem that was really in their setup.

## What Could Happen If You Install a Free Indicator Without Checking?

The story below is a composite example written for illustration. It is not a real trader's result, and no numbers are attached to it.

Picture a trader named Leo. He is learning SMC and has spent three evenings drawing order blocks by hand. He finds a file on a forum that promises clean labels for free. He copies it into the Experts folder, because that is where he thinks trading tools go. Nothing appears on the chart.

Leo searches for a fix. He reads a post that says to turn on DLL imports. A pop-up asks for a licence code, and he closes it to keep going. He restarts the terminal twice. A week later Leo still cannot say which change fixed anything, or whether anything did. He has no log of errors. He has no written loss limit. He has spent his practice time on installation and none on testing the logic he wanted to learn.

Leo's problem was not a lack of ability. He skipped the checks that take minutes, and he made changes without recording them. Every week spent guessing is a week of chart time you cannot learn from. The fix is a simple routine that you follow in order and write down as you go.

## How Do You Check a Free Download Before You Install It?

Start with the source. Download the file only from the original author or from a page the author controls. If the file has been re-shared across several sites, you cannot easily tell which copy is the original. A clear source is the first thing to look for, and the absence of one is a warning sign.

Next, scan the file with your own antivirus before you open it. The checklist makes the same point in its first section: download the file from the original source and scan it before use. Do not run an installer you did not expect. An MT4 indicator should arrive as a single compiled file, not as a bundle with extra programs attached.

Then confirm the file type. An .ex4 file is built for MT4, and an .ex5 file is built for MT5. An .ex4 will not run on MT5, and an .ex5 will not run on MT4. Some authors also share an .mq4 or .mq5 source file. Source code is easier to inspect, but it may need to be compiled in MetaEditor before your terminal can use it. If you cannot read the source, you cannot verify what the compiled file does, and that is a limit you should accept honestly.

Read the licence terms next. Check how many accounts the licence covers, which account numbers are allowed, and whether a demo account counts for testing. A licence that restricts use is not automatically a scam, but it tells you what you are allowed to do before you spend time on setup.

Finally, watch for red flags. Be cautious if a page forces you to enable DLL imports without a clear reason. Be cautious if a file asks for a licence code, opens a pop-up you cannot explain, or pushes you toward a bundled installer. Walk away from any page that promises trading profits or pressures you with a countdown. Nobody can promise trading results, and a reputable author will not try to.

## Where Does the SMC Indicator Go Inside MT4?

The standard MT4 route is simple, but it is easy to put the file one folder off.

1. Open MT4.
2. Click File, then Open Data Folder.
3. Open the MQL4 folder, then the Indicators folder.
4. Copy your .ex4 indicator file into Indicators.
5. Right-click Navigator and choose Refresh, or restart the terminal.
6. Find the indicator in the Navigator and drag it onto your chart.

Wrong folder is the most common mistake. An indicator placed in the Experts folder will never attach, because the terminal looks for indicators in the Indicators folder. EAs belong in Experts. Keep the two separate, and you will avoid most "it does not appear" reports.

Libraries are a separate case. A .dll file goes in MQL4/Libraries only when the vendor tells you to use one. If the vendor gives no reason, leave "Allow DLL imports" switched off. You can always turn it on later if a documented requirement appears.

If you have an MQ4 source file instead of a compiled file, open it in MetaEditor, compile it, and read the compile log for errors. The compiled .ex4 should then appear in the Indicators folder. If compile errors appear, our guide to fixing compile errors in MQL4 walks through the usual causes, step by step.

If you move to MT5, the same idea applies with the MQL5 folders and .ex5 files. The MQL5 Indicators and Experts folders play the same roles as their MT4 equivalents.

## Why Does the Terminal Still Block the Indicator or EA?

Sometimes the file is in the right place and the terminal still refuses to act. Three settings do most of the blocking, and the checklist covers each one.

First, automated trading must be allowed. In MT4, open Tools, then Options, then the Expert Advisors tab, and tick "Allow automated trading." In MT5, the same tab offers "Allow algorithmic trading." The AutoTrading or Algo Trading button in the toolbar must also be green. If it is red or grey, the terminal is not allowed to run EAs.

Second, look at the chart icon. Next to the name of an attached EA, a smiley or hat icon shows whether it is allowed to run. If the icon has a cross on it, trading is disabled for that chart. Indicators behave differently: they draw but do not place trades. Keep the two cases apart in your head, because an indicator that draws is not proof that an EA can trade.

Third, read the logs before you change anything. Open the Experts tab and the Journal tab at the bottom of the terminal. The error line usually names the real cause, such as a missing file, a blocked import or a rejected setting. Read it, write it down, and only then change one thing. Changing several settings at once makes it impossible to know which one helped.

If the logs show an error you cannot identify, stop. Do not raise the lot size, do not move to a live account, and do not turn off your broker's protections to make the file run. An EA you cannot explain is one you cannot risk-manage. If an EA worked before a terminal update and stopped afterwards, our guide on MT4 EAs that stop working after an update covers the most common causes.

## How Do You Set Up the Chart Without Drowning in Labels?

A clean first setup matters more than a complete one. Start with the chart the vendor specifies. If the vendor names a symbol and a timeframe, open exactly that combination. Indicators can look different across timeframes, and an SMC tool tuned on one may be noisy on another.

Next, check the symbol name. Many brokers add a suffix to symbol names, so EURUSD may appear with an ending attached. If the vendor's file is written for one name and your chart uses another, the indicator or EA may read no data, or it may trade nothing. Match the suffix before you blame the file.

If the vendor provides a .set file, load it. A set file stores input values. Then change only the lot or risk inputs on your first run, and leave the rest alone until you understand what each one does. This is the same principle the checklist applies to EAs: change as few things as you can.

For SMC indicators in particular, start small. Turn on the structure labels first, and keep the number of displayed zones low. Turn off alerts until you trust the signals. A chart full of boxes teaches less than a chart with three clear zones you can explain. Many beginners switch every feature on and then cannot tell which label matters.

Record your starting setup in a table, so you can return to it when something changes:

| Setting | Start with | Why |
|---|---|---|
| Symbol | The vendor's named pair, with your broker suffix | Avoids the most common "no trades" cause |
| Timeframe | The one the vendor specifies | Labels change with the timeframe |
| Set file | The vendor's .set file, if one is provided | Keeps the inputs consistent |
| Lot or risk | The smallest value you can accept on demo | Limits the cost of a bad first run |
| Alerts | Off | Lets you learn the labels before you react to them |

## How Do You Test Whether the Indicator Repaints?

Repainting is one of the biggest concerns with SMC tools. A repainting indicator changes its labels or zones after a candle has closed, which makes past signals look better than the live chart ever showed. You cannot trade a label that disappears.

Test it yourself on a demo account. Attach the indicator to your chart and wait for a few new candles to close. Take a screenshot after each close, or write down exactly which zones and labels are visible. Come back after a few candles and compare. If a zone moved, a label changed or a structure point shifted, the indicator is at least partly repainting on that setup.

Repeat the test on at least two pairs, such as EURUSD and GBPUSD, and across two market conditions: one trending period and one ranging period. A single clean session tells you very little. Several sessions across different conditions tell you whether the tool behaves consistently.

You can also use the MetaTrader Strategy Tester to replay historical data and watch how an indicator or EA draws and trades bar by bar. MetaTrader's own help pages explain how the tester works, and the MT5 page is listed in this post's sources. Treat it as a learning aid, not as proof of future results.

Finally, confirm that the indicator does not freeze the terminal or flood the Experts log with messages. A tool that spams errors is hard to trust, and the log is where your real problems will show up.

## What Should Your First-Week Log Record?

A log turns vague impressions into evidence. The checklist includes a five-day table, and it is worth filling in even if you only trade on demo. Each row covers one day, with five columns.

| Column | What to write |
|---|---|
| Day | The day of the week or the test day number |
| Trades | How many trades the EA produced, or how many signals you acted on |
| Log errors? | Yes or no, and the exact error line if yes |
| Max floating loss | The worst open loss you saw that day, in money or percent |
| Notes | Anything unusual, such as a restart, a setting change or a missed signal |

Fill it in as you go, not at the end of the week from memory. Copy the error line exactly as the terminal shows it. A rough note such as "some errors" is useless when you try to fix the problem later.

Record the maximum floating loss too. A demo account can hide the cost of a bad position, because a losing trade feels abstract when no real money is at stake. Writing down the worst floating loss builds the habit of checking risk, which you will need before any live trading.

For many beginners, the most useful entry is the note about what you changed. If you adjust one input on Tuesday and the errors stop on Wednesday, you want to know that. Without the note, you cannot repeat the fix or explain it to anyone.

## How Should You Read SMC Labels Without Overtrading?

Once the indicator works and passes your demo checks, the next risk is overtrading. Labels make a chart look busy, and busy charts tempt you to act on everything. A simple routine keeps you selective.

Start with the higher timeframe. Use H1 or H4 to decide the broad direction, and note the recent highs and lows that matter. Then wait for a structure event on your working timeframe. Many SMC traders look for a change of character followed by a break of structure, but your own model may order these differently. Write down the order you use and stick to it for the whole test.

Next, mark liquidity. Equal highs and equal lows are common places where stop orders sit, so they are common targets for price. Mark them before you look for an entry. Then take a setup only when it appears near a meaningful zone, such as an order block or a fair value gap, and not in the middle of open space.

Finally, check the risk before you enter. If the distance to your stop is too large for the size you are allowed to trade, skip the trade. Skipping is a valid decision, and much of the discipline in this method comes from skipping.

## What Should You Do If the Indicator Still Does Not Work?

If you have followed the checks and the indicator still fails, use the logs as your guide, in this order.

If the Experts or Journal log shows a compile or syntax error, the problem is in the file, not in your chart. Compile errors often come from a mismatch between the source and your MetaEditor version, a missing include file or a typo in the code. Our [step-by-step guide to fixing MQL4 compile errors](/how-to-fix-compile-errors-in-mql4-complete-step-by-step-guide/) shows how to read the message and where to look first. If you do not have the source code, the safest move is to ask the original author for a fixed version or to choose another file.

If the indicator worked before a terminal update and then stopped, the update may have changed how the platform handles the file. Check whether the file was built for your current build, then compare your settings with the version you last used. Our guide to [MT4 EAs that stop working after an update](/mt4-ea-not-working-after-update-fix-best-proven-solutions/) covers the usual causes and fixes.

If you prefer to study the logic on a charting platform first, our [review of order block tools for TradingView](/best-order-block-indicator-tradingview/) can help you compare what different tools mark and why. Remember that TradingView uses Pine Script, not MQL4, so a script there does not run on MT4 directly.

If you cannot identify the error after an honest search, stop. Do not change the lot size, do not switch to a live account, and do not disable your broker's protections. Return to the checklist, record what you tried, and either test a different file or ask the original author for help.
