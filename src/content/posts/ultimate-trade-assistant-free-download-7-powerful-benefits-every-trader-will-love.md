## Why do free trade assistants attract so many downloads?

Free trade assistants attract downloads because they promise less work. They sound like a second pair of eyes that never gets tired. For a beginner watching charts after a day job, that promise is strong. For an experienced trader who is short on time, it is just as strong.

The appeal has three parts. The first is speed. A tool can watch several symbols at once and tell you when a condition you defined has been met. The second is discipline. A written rule feels safer than a gut feeling at two in the morning. The third is cost. Paid trading software can be expensive, so a free option looks like a sensible test.

Those reasons are real. The problem is that they describe what you hope the tool will do, not what the file actually does. A free download does not come with a sales page that answers to you. Nobody has to reply to your support email. Nobody is required to explain what changed between versions. So the burden of checking falls on you.

There is also a quiet trap. When a tool feels helpful, you start trusting it before you have tested it. You stop checking the chart yourself. You stop writing down your trades. If the tool is wrong, you find out late, when the balance has already moved. The lesson is simple. A helper is only useful when you still understand the trade it is helping with.

## What does a trade assistant actually do inside MetaTrader?

A trade assistant is a file that runs inside your trading terminal. On MetaTrader 4 and MetaTrader 5, that usually means one of three file types. Custom indicators draw lines, arrows or panels on a chart. Expert Advisors, usually called EAs, can place, modify or close orders when their rules are met. Scripts run once and then stop. The code is written in MQL4 for MetaTrader 4 and in MQL5 for MetaTrader 5.

Many assistants combine these ideas. One file might show an alert, draw a stop level, calculate a lot size for a fixed percentage of your balance, and in some cases send an order. Each feature does something different, and each carries a different level of risk. An alert cannot close a trade for you. An EA can open a trade while you sleep. You should know which one you have before you attach it to any chart.

The word assistant is a marketing word. It does not tell you how the code works. The only honest way to find out is to read the file type, check the inputs, and watch what the tool does on a demo account. Do not assume that a panel means good analysis, or that an order button means good decisions.

Two terms are worth explaining once. A compiled file ends in .ex4 or .ex5 and is ready to run. A source file ends in .mq4 or .mq5 and must be compiled in MetaEditor before it works. If you have never compiled anything, read our guide on [how to fix compile errors in MQL4](/how-to-fix-compile-errors-in-mql4-complete-step-by-step-guide/) before you try. The difference also changes your check. A compiled file hides its logic, so you cannot read what it does. A source file can be read, but only if you know enough to follow it. Either way, testing carries most of the weight.

Visual tools need the same care. If you want to see how a chart indicator is judged on structure rather than on its drawings, our post on the [order blocks indicator for MT4 and MT5](/order-blocks-indicator-for-mt4-mt5-free-download-7-powerful-benefits-smart-traders-cant-ignore/) walks through what to look for, and the same questions apply to any helper you find.

## How do you check any MT4 or MT5 tool before you trust it?

Check any tool on a demo account, on a clean terminal, and only after you know what the file is. This takes time. It is also the only reliable way to separate a useful helper from an unsafe one.

Step one is to use a demo account. Open one with a broker you already use, or with a demo provider you trust. While you test, keep your live account logged out of the terminal. Never attach an unknown file to a terminal that holds live login details.

Step two is to write down what you downloaded. Note the file name, the file size, the date, and the folder it came from. Keep the original archive. If something goes wrong later, you will want to know exactly what you added and when.

Step three is to scan the file. Run a full antivirus scan on the archive and on the extracted files before you copy anything into MetaTrader. Do not switch off your security software to make a download work. If it flags a file, stop and treat that flag as a warning, not a nuisance.

Step four is to identify the file type. A .ex4 or .ex5 file is compiled. A .mq4 or .mq5 file is source code. An ordinary .exe file is not a MetaTrader tool at all, and you should not run it to test a trading helper.

Step five is to read every permission prompt. MetaTrader asks whether a file may import DLLs or allow live trading. If a prompt appears that you do not understand, click no and investigate. A tool that needs DLL access may do things well beyond drawing on a chart. Ask why before you say yes.

Step six is to check the inputs. Every MetaTrader tool has input settings. Read each one. If a setting mentions lot size, stop loss, or account login, check it twice before you leave the default in place.

Step seven is to watch at least one full trading session on demo. Note every signal, alert and order. Compare what the tool shows with your own reading of the chart. If it draws a level you cannot justify, that is information. Write it in your log.

If the file loads but nothing happens, do not guess. For a deeper look at how testing works in MetaTrader 5, read the official [MetaTrader 5 help on testing automated trading systems](https://www.metatrader5.com/en/terminal/help/algotrading/testing). It explains how the Strategy Tester replays past data, which is useful when you want to see how a rule behaved before you watch it live on demo.

## Why should you open the Trading Tools folder with caution?

The download button on this page opens a shared Google Drive folder named Trading Tools. Folders like this are convenient, but they are also easy to change. Files can be added, replaced or renamed after someone has read about them. So before you copy anything, slow down and check what you actually have.

Start with the file name. Confirm that the file you downloaded matches the name you expected to find. If the name is different, or if there are several files with similar names, stop. Do not guess which one is the right one. Ask yourself why there would be several.

Next, check the archive. If you receive a ZIP file, extract it into a new, empty folder, not straight into your MetaTrader data folder. Look at the list of files before you move anything. If you see executable files you did not expect, or a file that looks like a setup program, do not run it. A MetaTrader indicator or EA is not a Windows installer, and a trading helper has no real reason to ask you to run one.

Then keep your broker details out of it. A drawing tool does not need your broker password to draw lines or calculate lot sizes. If a file asks for your login, your password or a card number, close it. Never type broker credentials into a third-party file, no matter how official the screen looks.

Think about where the file will live once it is inside MetaTrader. The data folder holds your history, your templates, your logs and your saved settings. A tool that writes into the wrong place can change how other tools behave, and that is hard to undo. Copy only into the Indicators or Experts folder, and nowhere else. If you are unsure which folder is which, stop and look it up before you paste anything.

Also think about which computer you use. A research machine, separate from the one that holds your broker session, limits the damage if a file behaves badly. Many traders keep a second Windows profile for testing. It costs nothing but a few minutes of setup, and it keeps your live login out of reach of anything you are still evaluating.

Finally, keep a clean record. Write down the date you checked the folder and the names of the files you tested. If the folder changes later, your record shows exactly what you looked at. That record is also useful if you need to ask a question or report a problem.

## How do you run a demo test that tells you something?

A useful demo test runs long enough to show more than one kind of market. One quiet afternoon tells you almost nothing. Plan several weeks of demo time, and make sure the period includes trending sessions, ranging sessions and at least one scheduled news release. Write the plan down before you start, so you cannot quietly stop the test on a good day.

Set up a log before the first trade. A spreadsheet or a notebook works. Use these columns: date and time, symbol, timeframe, what the tool showed, what you would have done without it, what the terminal did, and any error message. Write each entry at the time it happens, not later from memory. Memory tends to tidy up the bad results.

Watch for three things during the test.

First, does the tool show the same signal every time you reload the chart? A tool that repaints redraws past values as new bars form. It can look perfect in hindsight and be useless in real time. Our post on [non-repainting divergence indicator settings](/non-repainting-divergence-indicator-settings-for-forex-trading-strategies/) explains how to test for this on your own chart.

Second, does the tool's behaviour match the spread and slippage your broker really gives you? Demo fills are not live fills. If the tool places orders, record the gap between the price you expected and the price you received. Over a few weeks, that gap is useful data.

Third, does the terminal log errors when the tool runs? Open the Experts tab at the bottom of the terminal. MetaTrader writes most failure reasons there. Check it at the start of each session, not only when something visibly breaks. A message that appears once and then stops can still matter, because it may explain why an order was skipped or why a level was not drawn. Copy the message into your log with its time stamp, so you can compare it with what the chart showed at that moment.

At the end of the test, count your entries and look at the pattern. Did the tool help you follow your own rules, or did it pull you into trades you would have skipped? That answer matters more than any screenshot a seller posts. Do not move to a live account until you have a written decision covering the setting you will use, the maximum risk per trade, the drawdown at which you pause, and the conditions under which you will switch the tool off.

## How much risk should you allow while you test?

Use a fixed, small risk on every demo trade, and keep a stop loss on every position. Many traders use 1% of their balance per trade as a practice starting point, because it makes a losing streak easier to study on paper. That number is an example, not a rule. It is not a promise that you will be safe at 1%, and a smaller number does not remove the risk either.

Position size should come from your stop distance, not from a feeling. If the tool calculates the lot size for you, check the maths once by hand. Take the account balance, multiply it by the risk percentage, and divide by the stop distance multiplied by the pip value. If the tool gives a different number, find out why before you trust it. A mismatch can come from a symbol setting, a deposit currency or a rounding rule.

A stop loss that is too tight gets hit by normal noise. A stop loss that is too wide makes each loss large. Our article on [the best ATR multiplier for stop loss](/the-best-atr-multiplier-for-stop-loss-a-comprehensive-guide/) explains one method for setting that distance from recent volatility. Treat it as a starting idea, then test it on demo before you rely on it.

Drawdown is the drop from a peak in your balance to a later low. Even a small risk per trade can produce a long drawdown in a bad run. Leverage makes every move larger in your account currency, including the moves that hurt. Decide in advance how much drawdown you can accept before you pause and review. If you cannot name that number, you are not ready for live trading.

Pay attention to the losing trades in your log as much as the winning ones. A losing trade that followed the rules is a normal cost of trading. A losing trade that broke your rules is a process problem, and no tool will fix it for you. Mark each entry as followed rules or broke rules. After a few weeks, the second group tells you more about your own habits than the tool does about the market.

Keep the rules simple while you learn. One pair, one timeframe, one tool, and one written risk limit is enough. Adding more symbols and more tools at the same time makes it impossible to tell which one caused a result.
